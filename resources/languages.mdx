AfriHealth AI is designed for code-switched speech, where clinicians and patients mix a local language with English in the same sentence. Speech is transcribed by the Intron Sahara v2.5 ASR engine, which keeps local disease descriptions grounded without translating them.

## Language scope

| Language pair | Status |
| --- | --- |
| Amharic-English | Active (v1.0) |
| Afaan Oromoo-English | Roadmap Phase 2 |
| Tigrinya-English | Roadmap Phase 3 |

## Example of code-switched input

From Gold Standard Case 3 (Pediatric Respiratory & High Fever):

> ልጅዎን ምን አመመው? severe cough እና high fever...

The transcript keeps both scripts as spoken, so clinicians can review the exact wording.

<Tip>
  Select your language scope in the Frontline Triage module before recording. Only Amharic-English is active in v1.0.
</Tip>
